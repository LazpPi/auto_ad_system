# 自動広告システム (auto_ad_system)

私が所属するゼミナール内で運営している「ゼミカフェ」のスマート化を目的としたシステムです。カフェブースの前を人が通ると自動でプロジェクターが起動し、指定した動画を再生します。


https://github.com/user-attachments/assets/ad14c9d3-613f-4fa5-a294-8dfcd0662ac3



## 1. プロジェクトの背景と目的
これまでゼミカフェの運営において、商品の宣伝は手作りのチラシをホワイトボードに貼り出し、コーヒーメーカーの使い方などはQRコードを掲示して利用者に読み取ってもらうというアナログな手法をとっていました。

しかし、この運用には以下の課題がありました。
* **広告の目立たなさ**: チラシは視覚的なインパクトが弱いため、目立たなくあまり意味をなしていない。
* **利用者の負担**: 少しだけ解説動画を見たい人にとって、わざわざスマートフォンを取り出してQRコードを読み取る作業はハードルが高く、大きな手間である。

これらの課題を解決し、利用者がブースの前に立つだけで自然と必要な情報が目に入ってくる環境を作るために、本システムを開発しました。
現在はコーヒーメーカーやスマート決済システムの使用方法の解説動画を流すために稼働していますが、今後は購買意欲を高めるための広告動画も流していく予定です。

## 2. 特徴
* **人感センサー連動**: 人が近づいた時だけ動画（.mp4）をループ再生。無人状態が続くと自動で待機モードに戻ります。
* **プロジェクター自動制御**: 赤外線（IR）を利用して電源を自動ON/OFFし、機器の消耗を抑えます。
* **過労防止・夜間スリープ**: 連続稼働時間の制限（強制クールダウン）および夜間帯の自動停止機能を搭載しています。
* **誰でも停止できる設計**: ゼミ生が研究等のためにプロジェクターを利用したい場合、誰でもシステムを停止（`Ctrl + C`）できるよう、キーボード一体型のラズパイを採用しています。

## 3. 必要なハードウェア
* Raspberry Pi 400（キーボード一体型モデル）
* Grove Base Hat for Raspberry Pi Zero（センサー接続用基板）
* M5Stack用 PIRセンサユニット（人感センサー）
* M5Stack用 赤外線送受信ユニット（プロジェクター制御用IRセンサー）
* プロジェクター

## 4. 依存ソフトウェア・ライブラリ
システムを動かすためには以下のインストールが必要です。
* Python 3.x
* `pigpio` (GPIO制御)
* `mpv` (動画再生)
* `cgir` (赤外線送信コマンド)

## 5. ディレクトリ構成
* `main_system.py`: メインの制御プログラム
* `video_player.py`: 動画再生のサブプログラム
* `codes.json`: 赤外線リモコンの信号データ
* （※動画ファイルなどの個人情報を含むデータはGit管理から除外しています）

## 6. 使い方
1. 本システムは、Raspberry Piの電源を入れると自動でターミナルが立ち上がり、システムが実行されるように設定されています。

2. **システムの停止方法**
   終了する場合は、ラズパイ本体のキーボードで `Ctrl + C` を押してください。安全にプロジェクターを終了し、プログラムを停止します。
